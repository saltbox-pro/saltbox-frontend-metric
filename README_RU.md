## Описание

**Salt.Box Frontend Metric** – микрофронтенд на Single-SPA, который добавляет в веб-интерфейс Salt.Box ссылки на мониторинг. Собственного UI у модуля нет, его корневой компонент всегда возвращает `null`. Единственная задача модуля – добавлять пункты в глобальное меню настроек, ведущие в Grafana.

Модуль зарегистрирован под именем `saltbox-frontend-metric` и монтируется по пути `/metric`.

## Меню настроек

Модуль регистрирует группу меню `Monitoring`, с двумя пунктами, каждый из которых локализован на английский и русский:

- **Dashboard**, ключ `dashboard`, ведёт на дашборд Grafana по адресу `/grafana/d/salt_box`
- **Logs**, ключ `logs`, ведёт в приложение Grafana Loki Explore по адресу `/grafana/a/grafana-lokiexplore-app`

Оба пункта используют обычные ссылки `href` в пределах того же origin, а не клиентскую маршрутизацию, поскольку открывают Grafana напрямую, а не какое-либо представление, отрисованное этим модулем.

## Условная загрузка

root-config монтирует этот модуль только тогда, когда сервис `metric` присутствует в `/api/discovery/config`, который отдаёт Gateway. Этот сервис регистрируется backend-ом модуля Metric, поэтому меню Monitoring появляется только когда модуль Metric действительно включён.

## Разработка

```bash
yarn install
yarn start
```

Запускается на порту `4206` через webpack-dev-server.

Чтобы разрабатывать модуль с локальной копией общего пакета `@saltbox/saltbox-frontend-common` вместо опубликованной версии, задайте в локальном файле `.env` переменную `COMMON_REPO_PATH` с путём к нему. Это подменяет пакет только для dev-сборки.

## Сборка и развёртывание

Команда `yarn build` собирает ресурсы с хешем в имени файла и дополнительно создаёт стабильный файл `index.js`, который реэкспортирует собранный бандл, поэтому точка входа, которую импортирует root-config, не меняется между релизами.

Сборку отдаёт nginx: ресурсы с хешем в имени кэшируются надолго и неизменяемо, а `index.js` и `index.html` отдаются с `no-cache`.

В `saltbox-metric-compose` модуль упакован как сервис `saltbox-metric-frontend`, тег образа задаётся переменной `METRIC_FRONTEND_IMAGE_TAG`, а проксируется через nginx-инклюд `10-metrics.conf` в `saltbox-compose`.
